# Exercise 01: Git Basics

This file covers the absolute fundamentals of Git that every workshop participant should know cold:

- `git init` / `git clone` to start working with a repository
- `git add`, `git commit`, and `git status` for day-to-day workflow
- `git log` and `git diff` for inspecting history

Work through this file first; it is the foundation for everything else in the lab.
